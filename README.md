# lpr-gauge

App para el móvil que envía por Bluetooth LE al cuadro de instrumentos de una
moto (un ESP32-S3 con pantalla redonda) la navegación —flecha del siguiente giro
y metros que faltan— y la altitud.

## Estado

Fase 0 (arranque): todavía no hay código. Las decisiones tomadas, sus fuentes y
lo que queda pendiente están en [docs/DECISIONES.md](docs/DECISIONES.md).

## Plataformas

- iPhone primero, con iOS 17 o posterior.
- Android más adelante, compartiendo todo el código que se pueda.
